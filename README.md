# FlyRank ML Capstone — CTR / Engagement Opportunity Scoring

This package contains the complete reproducible capstone based on the supplied FlyRank dataset.

- Rows: 30,000
- Columns: 53
- Lane: CTR / Engagement Opportunity Scoring
- Final ranking model: Logistic Regression
- Grouped validation: 80/20 by client
- Logistic Regression test F1: 0.687
- Logistic Regression test ROC-AUC: 0.967
